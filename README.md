# Applied Data Science Learning Lab

A self-directed, eight-week learning companion covering statistics, experimentation, causal inference, Python, SQL, applied machine learning, and analytical problem solving.

**Purpose:** A general professional development and technical learning resource. All examples are educational and use synthetic or public-domain scenarios. The application contains no employer-specific data or proprietary work material.

## What's included

- **Overview:** Study goals, weekly progress, assessment activity and study hours.
- **Learning pathway:** 8 weeks, 48 topics, curated study references and weekly notes.
- **Resource library:** Free university lectures, open textbooks, and practical courses.
- **Practice lab:** Local multiple-choice quiz bank with explanations, grading and topic-level feedback.
- **Flashcards:** Quick recall questions and explanations.
- **Progress insights:** Study time, assessment history and areas to revisit.
- **Study notebook:** Week-by-week notes saved on your device.

## Run locally

No build tools, dependencies, API keys or external accounts are required:

1. Download or clone the repository.
2. Open `index.html` in your browser.

For a local development server, run `python3 -m http.server 8000` in the repository folder and navigate to `http://localhost:8000`.

## Publish on GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Save and follow the Pages link once GitHub publishes it.

Expected project URL (once Pages is enabled):
https://medhavidarsha.github.io/applied-data-science-lab/

Publishing requires GitHub Pages to be enabled in the repository settings. Committing the files alone does not activate hosting.

## Progress and privacy

- All progress, quizzes and notes are stored in browser `localStorage`.
- Quiz questions and answers ship with the static application; no AI API calls are made.
- The application does not upload your notes or scores to GitHub.
- **Export data** creates a JSON backup. You can import that JSON in another browser.
- Browser storage is specific to a browser/device and can be cleared. Make regular backups.
- The repository is public, so only commit files intended to be public.

## Technology

Plain HTML, CSS, and JavaScript; no build dependencies or server required.

## Limitations

The built-in quiz bank contains a finite number of reviewed questions; options are shuffled by question ordering, not generated by an AI model. The application will cap requested quiz length to the matching bank size. This is a practical self-study tool, not an accredited assessment or official course certification.
